# 第 7 窗口：整体验收与展示

## 目标

基于最终版代码，核对 Stage 2 真实部署，完成约 17 分 41 秒授权样片的当前版本浏览器闭环、Stage 4–6 隔离故障回归、数据库/资源/费用核验，并交付可复现运行说明和脱敏展示材料。

## 范围

- 修复已确认的 ORM 与 Stage 5 冷却索引差异；保留索引，不改写已应用迁移。
- 补齐轻量、事务内、幂等的分析时间线；PostgreSQL 当前状态仍是事实源。
- 在新账户和新记录中完成真实分片续传、ASR/LLM、摘要引用播放、API/Worker 重启读回和两种删除。
- 用隔离 Compose 与本地模型替身回归限流、执行中断、队列、停止证明、预算和媒体清理故障。
- 核对 20 分钟媒体边界、供应商公开免费/可用信息、账户价格与账单证据、Docker 与 E 盘资源。
- 更新验收矩阵、验证索引、展示说明及 README、产品/技术进度；按逻辑单元提交。

## 非目标

- 不重置或切换分支；不更改历史业务记录、旧冻结配置或已应用迁移；不清理其他项目的数据或 Docker 资源。
- 不扩展产品范围，不构建新事件总线，不把本地替身故障描述为真实供应商故障。
- 不把旧窗口通过记录或本地零费率配置当作本窗口真实模型、账户账单或完整 20 分钟模型证据。

## 不可妥协项

仅在模型价格已确认免费时调用真实供应商；不自动转付费模型。原文、媒体、账号凭据和模型响应仅保存在 Git 忽略的本地目录。未确认 execution 不接管、不强制清理。最终结论分别判定窗口完成度、最终版标准和当前演示能力；所有未验证项明确保留。

## 完成标准

按[验收矩阵](acceptance-matrix.md)逐项收集当前证据。当前结论为：第 7 窗口**部分完成**，最终版既定标准**部分满足**；缺少供应商账户侧调用后用量/账单证据，20 分钟真实模型处理未运行，完整 Stage 7 Playwright 用例未获得一次全绿结果。其余真实长视频流程和隔离故障链路按[验证记录](validation.md)分层说明。
